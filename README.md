# Defensive Cybersecurity Journey

A deliberate, beginner-friendly journey toward defensive cybersecurity, guided by Professor Sentinel.

## Goal

Over the next 7–8 months, I will build strong foundations for entry-level defensive cybersecurity roles, a credible public portfolio, appropriate certifications, and Germany-first university applications.

My target areas are:

- Security operations and SOC analysis
- Incident response and threat detection
- Security engineering and cloud security
- Vulnerability management
- Governance, risk, and compliance

I will study offensive concepts only in legal, approved training environments to understand and improve defenses.

## Learning principles

- Start from absolute zero and do not skip foundations.
- Learn slowly, practise safely, and document what I understand.
- Use only authorised labs and learning platforms.
- Prioritise durable skills and evidence of work over collecting badges.

## Roadmap

### Phase 1 — Computer, terminal, and Linux foundations

- Computer hardware, operating systems, files, processes, users, and permissions
- macOS Terminal and Linux command line
- Safe command-line practice and basic troubleshooting

### Phase 2 — Networking fundamentals

- TCP/IP, OSI model, IP addressing, DNS, DHCP, HTTP/HTTPS, ports, and protocols
- How networks communicate and how defenders investigate network activity

### Phase 3 — Programming and version control

- Git and GitHub
- Python fundamentals for automation and log handling
- Bash basics and SQL fundamentals

### Phase 4 — Defensive cybersecurity foundations

- Security principles, threats, vulnerabilities, and controls
- Authentication, authorisation, identity and access management
- Cryptography basics, vulnerability management, and secure system practices

### Phase 5 — Blue-team practice

- Logs, SIEM concepts, alert triage, endpoint monitoring, and detection
- Incident response and threat intelligence
- Cloud-security fundamentals
- Approved hands-on practice through TryHackMe, LetsDefend, and Blue Team Labs Online when ready

### Phase 6 — Portfolio, certifications, and applications

- Safe incident-analysis write-ups and small Python projects
- Professional CV and LinkedIn profile
- Certification preparation only when foundations are ready
- Reputable German university research and application preparation; Ireland is a fallback
