# Class 3 - Hidden Files

## What I practised

- I used ls -a to display all files and folders, including hidden items.
- I learned that period(.) at the beginning of a file name marks a hidden file, also called a dotfile.
- I learned that (.) means the current folder and (..) means the parent folder.
- I created a harmless hidden practice file named .lesson-03-hidden-file.
- I confirmed that normal (ls) hides dotfiles, while (ls -a) displays them.

## What I learned

- Hidden files are often legitimate configuration files. They are not automatically dangerous, but defenders should include them when inspecting a system.
