# Class 1 - Terminal Basics

## What I Practised

- I used pwd to see my current folder.
- I used ls to list the files and folders in my current folder.
- I used mkdir to create the cybersecurity and practice folders.
- I used cd to move between folders, and cd .. to move back one folder.
- I used touch to create notes.txt and cat to display what I saved in it.
- I used whoami, date, and uname to identify my signed-in account, the current date and time, and my Mac's operating-system family.

## What I Learned

Terminal commands let me navigate folders and inspect files carefully. This is an important foundation for defensive cybersecurity.
