# Class 5 - Paths

## What I Practiced

- I used 'pwd' to display my current folder' full path.
- I used 'cd ~/Cbyersecurity/practice' to move to my practice folder using the home-folder shortcut.
- I used 'cd ..' to move to the parent folder.
- I used 'cd practice' to move into a folder inside my current location.
- I used 'cd' with no destination to return to my home folder.
- I used 'cd Cybersecurity/practice to move through two folders using a relative path.

## What I Learned

- An absolute path starts with '/' and gives the complete folder address.
- A relative path start from the folder Terminal is currently using.
- '..' means the parent folder, one level above the current folder.
- '~' is called a tilde  and means my home folder, /Users/shadow.
- '/' is called a forward slash and separates folder name in a path.
